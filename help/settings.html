Settings

The menu bar runs across the top of the main window: File, Tools and Help open menus, and Save and Load sit beside them as one-click actions for the deck on screen rather than as menus. Tools opens the six companion windows (Opponent Tracker, Timer Alert, Match History, Metagame Analysis, Top Cards and Radar). Everything on this page lives in File, in Help, or in the Preferences dialog that File ▸ Preferences… opens.

File menu

File also carries the deck file actions — Load Deck…, Save Deck… and Save Collection Diff… — at the top, and Exit at the bottom.

ItemDescription
Load Collection Triggers a refresh of your MTGO collection via the MTGOBridge component (.NET). After loading, each card row in the Deck Workspace shows how many copies you own. Requires the .NET bridge to be available.
Enable Offline Images Mode Opens a dialog to bulk-download card images from Scryfall. You can choose to download images only for cards in your current deck, or for all cards in the database. Downloaded images are cached locally and used by the Card Inspector.
Update Card Database Forces a fresh download of the card metadata database (names, costs, types, oracle text) from MTGJSON. This is required before the Deck Builder can search cards.
Export Diagnostics Exports a diagnostics bundle (logs, settings, version info) to help with bug reports. No personal or account data is included.
Check for Updates… Asks GitHub right now whether a newer version has been published, and says what came back. It works whether or not the automatic check below is switched on.
Preferences… Opens the Preferences dialog described below.

Help menu

ItemDescription
Help (F1) Opens this help system. You can also press F1 at any time.
Show Tutorial Reopens the first-run tutorial wizard that introduces the main features of MTGO Tools.
Comprehensive Rules Opens the Magic Comprehensive Rules browser.

While an update is pending, a Get MTGO Tools v… entry appears at the end of this menu. It is there only while there is something to install.

Preferences

Open with File ▸ Preferences…. The six settings are grouped by what they affect, and each takes effect as you change it — there is no OK button, only Close.

SettingDescription
Deck data source
(Deck data)		 Which site deck lists are fetched from: Both (the default, and the widest coverage), MTGGoldfish only, or MTGO.com only, hydrated from the published metagame bundle.
Default deck folder
(Deck data)		 Where Save Deck and Load Deck open. When it is not set, or the folder no longer exists, they open in your Documents folder.
Average method
(Archetype averages)		 How an archetype average deck is built. Karsten’s weights each card by how often it is played; Arithmetic takes the plain mean.
Average time window
(Archetype averages)		 How far back the archetype average and the Deck Results list look — 12 to 72 hours.
Language
(Application)		 English or Português (Brasil). Menus and labels re-translate immediately; a restart is needed for the rest.
Check for updates
(Application)		 The automatic daily check, described below. On by default.

Check for updates

When enabled (the default), MTGO Tools asks GitHub once a day whether a newer version has been released. If one has, an Update available note appears at the right-hand end of the status bar and a Get MTGO Tools v… entry appears at the top of this menu; clicking either opens the release page in your browser, where you can download the installer.

The check runs in the background and never interrupts you. If you are offline it does nothing at all. Nothing is downloaded or installed automatically — updating is still a matter of running the installer yourself. Untick Check for updates to switch the check off entirely.

Session state

The following are saved automatically and restored on the next launch:

  • Selected format.
  • Left-panel mode (Research or Builder).
  • Current deck text and zone contents.
  • Window size and position.
  • Language and deck data source selections.
  • The Check for updates preference.

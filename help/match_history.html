Match History

The Match History window parses your MTGO GameLog files and displays a summary of recent match results. Open it with Tools ▸ Match History on the menu bar.

GameLog location

MTGO is a ClickOnce application, so it writes its Match_GameLog_*.dat files into a hashed folder under your local application data:

%LocalAppData%\Apps\2.0\Data\...\mtgo...\Data\AppFiles\...\

You are not expected to find that yourself, and there is nothing to configure. MTGO Tools asks the MTGO bridge where the logs are, and if the bridge cannot say, it walks that tree itself for any folder holding GameLog files and uses the one written to most recently.

Displayed information

One row per match, in five columns:

  • Players (Archetypes) — both usernames with the archetype each was playing, as you (your deck) vs opponent (their deck).
  • Format parsed from the log.
  • Result — Won or Lost, with the match score.
  • Mulligans — your total for the match, with the per-game counts beside it.
  • Date and time of the match.

Double-click a row to see both players’ decklists as they were recorded in the log.

Filtering

The filters sit in the Win-Rate Metrics panel above the list and scope the figures in it, not the rows below: the list always shows every match parsed, and Match Win Rate (filtered) and Game Win Rate (filtered) are the numbers that move.

Enter a Start and End date (YYYY-MM-DD) and click Apply Dates for a date range. Below them, the Format, My deck and Opponent deck dropdowns narrow it further and apply as soon as you pick; each is built from what is actually in your history, and All turns that one off. Select a row and the panel also reports your match win rate and mulligan rate against that opponent, under the same filters.

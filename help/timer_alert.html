Timer Alert

The Timer Alert window watches the countdown MTGO itself runs on a challenge or league match and sounds an alert as that clock passes times you choose. It does not run a countdown of its own: it reads MTGO’s timer through the MTGO bridge, so it needs the bridge to be available and MTGO to have an active timer before it can report anything.

Opening the timer

Choose Tools ▸ Timer Alert on the menu bar. The window floats above other windows so it remains visible while you play.

Controls

ControlDescription
Alert Thresholds The list of times — entered as MM:SS of time remaining — at which an alert fires. One entry starts at 05:00; + Add Another Threshold adds another and ✕ removes one. The list is locked while monitoring is running.
Alert Sound Which Windows system sound plays: Beep, Alert, Warning, Question or Default.
Check interval (ms) How often the window re-reads MTGO’s timer. 1000 ms by default; 250 to 5000.
Repeat interval (seconds) How often Repeat alarm at interval sounds again. 30 seconds by default.
Alert when timer starts counting down Sounds one alert as soon as a timer is first detected, before any threshold is reached. Ticked by default.
Repeat alarm at interval Keeps sounding the alert every repeat interval once the countdown has started. Off by default.
Start Monitoring / Stop Starts and stops watching. Stop also unlocks the thresholds for editing.
Test Alert Plays the selected sound once, so you can check it is audible before you rely on it.

Alert behaviour

While monitoring, the window re-reads MTGO’s timer at the check interval and plays the chosen sound once for each threshold the remaining time has fallen to or below. Each threshold fires once; they are all armed again when MTGO’s timer goes away. The alert is a sound and nothing else — the window neither flashes nor comes to the front, which is why it is set to stay above other windows.

The status line reports what the window is doing — waiting for MTGO data, no active challenge timer, the current remaining time, or a bridge error — and Active Challenge Timer below it shows what the bridge last read.
